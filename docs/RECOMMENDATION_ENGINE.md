# FilmMirror 推荐与画像引擎 v2

## 为什么重做

v1 将用户选中电影的标签去重后再计算。结果是“科幻”连续出现 6 次与某个长尾标签只出现 1 次拥有相同权重，雷达图、人格名、推荐列表和分享海报又分别使用不同的评分方法，容易出现输入与结果断裂。

## v2 的统一计算链

1. 从用户选中的电影中统计标签出现次数。
2. 仅保留用户在标签确认页认可的标签；用户手动添加的标签按一次显式信号计入。
3. 使用 `count ^ 1.45` 放大重复信号，使核心类型偏好高于偶发长尾标签。
4. 将同一份偏好画像映射为六维得分，最高维度校准为 95，其他维度按相对强度展开，避免多个维度同时饱和。
5. 推荐排序由标签吻合度（68%）、六维余弦相似度（22%）和高频标签覆盖（10%）共同组成。
6. 人格名、推荐列表和分享卡海报全部复用同一份画像与排序逻辑。

## 可解释性

- 画像页展示前 5 个主要依据及出现次数。
- 每条推荐展示最多 3 个匹配原因。
- 推荐匹配度是排序分数的可读化结果，不再使用“命中标签数 / 候选电影标签数”的旧算法。

## 回归场景

固定选择片库前 8 部科幻/悬疑电影：

- v1：内省深度 64、逻辑分析 51；分享卡海报包含《摔角王》《鲸》《童年往事》等弱相关影片。
- v2：逻辑分析 95、内省深度 91；人格为“烧脑选民·意识迷宫”。
- v2 推荐前五为《红辣椒》《月球》《2001太空漫游》《未麻的部屋》《机器人瓦力》，每一项均展示科幻、悬疑、心理、虚实难辨等匹配依据。

## 性能调整

- 六维雷达图由 Recharts 改为原生 SVG。
- 分享卡及其截图依赖改为点击后懒加载。
- 自动庆祝粒子不再遮挡雷达图。
- 画像页面业务包由约 162KB gzip 降至约 4KB gzip；共用画像引擎约 9KB gzip，分享卡约 57KB gzip，仅在用户点击生成时加载。

## 下一步验证指标

- 画像认同率：结果页“点赞”或正向反馈比例。
- 推荐点击率：推荐电影被点击或收藏的比例（需补充行为入口）。
- 推荐解释展开/反馈率：用于定位错误标签与错误映射。
- 重测率：短期异常高可能意味着画像不符合预期。
