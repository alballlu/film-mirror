# FilmMirror 画像文案与职业探索引擎 v2

## 旧版问题

- 画像总结只有 5 段模板，大量使用“灵魂、秘密、命中注定”等抽象表达。
- 六个维度分别只有高、中、低三段固定解释，用户更换片单后仍容易看到同一句话。
- 职业结果将最高三个维度对应的职业直接合并，缺少岗位之间的逻辑，也没有告诉用户下一步如何验证。
- 分享卡宣言每个主维度只有 3 句，且不引用用户真实选片证据。

## 新版原则

1. 先说证据：展示选片数量、反复出现的标签及次数。
2. 再做解释：描述用户如何看故事，避免把观影偏好包装成人格诊断。
3. 保留边界：低分只表示本轮选片没有强化该信号，不表示用户缺少某种能力。
4. 职业结果改称“工作方式探索”，不再给出一串互不相关的岗位。
5. 每条路径必须包含岗位族、出现原因、常见工作方式和低成本验证任务。

## 文案组合方式

- 主画像由高频标签证据、主维度观察、前两维度关系和最低维度边界动态组合。
- 六维解释按分数档位选择 2—3 种人工编写表达，并加入该维度真正对应的选片标签。
- 分享卡宣言按主维度选择表达骨架，再填入本次最高频的两个标签。
- 所有结果确定性生成：同一组输入保持一致，不依赖在线大模型，不增加接口成本与等待时间。

## 职业路径计算

候选路径包括：

- 产品与用户策略
- 数据、商业与行业研究
- 咨询、战略与公共议题
- 内容策略与叙事表达
- 体验设计与品牌表达
- 用户运营与组织协作
- 影像与创意项目

排序以六维适配为主、实际高频标签为辅，展示前三条，并区分“优先探索、值得验证、保留选项”。这些结果只用于生成探索假设，不替代能力、经历和机会约束下的真实职业决策。

## 回归案例

科幻/悬疑片单的前三路径为：

1. 数据、商业与行业研究
2. 产品与用户策略
3. 内容策略与叙事表达

每条路径均给出可在一到两天内完成的验证任务，而不是以“适合某职业”结束。
