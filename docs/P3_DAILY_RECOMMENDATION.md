# FilmMirror P3：今日电影推荐闭环

## 目标

把“今天该看什么”从氛围猜测改为可解释、可反馈的推荐工具，同时保留 FilmMirror 的品牌感。

## 输入信号

1. 期望结果：轻松、想哭、烧脑、兴奋、恐惧、力量或惊喜。
2. 明确类型：最多选择两个类型，作为最强推荐信号。
3. 观影投入：短时、标准或长片，用于动态片源筛选。
4. 内容边界：沉重、恐怖、血腥、慢节奏、恋爱主线、开放结局，可多选或跳过。

天气、旅行目的地和感情状态不再参与主排序，避免弱相关或越界推断。

## 推荐策略

- 镜子：类型命中、期望结果命中与避雷约束综合得分最高的稳妥选择。
- 窗户：保留期望结果，但在类型或表达方式上主动增加差异，减少过滤气泡。
- 片源：172 部本地精选池即时返回；Cloudflare Function 代理 TMDB Discover 动态补充至线上候选池。在线请求失败时保持本地结果可用。
- 解释：展示命中的类型、情绪效果、时间条件和已规避边界，不使用情绪诊断式文案。

## 反馈闭环

每条推荐支持“想看 / 看过 / 不想看”。“不想看”继续收集类型不对、看过、太沉重、节奏不合适和没眼缘等原因。反馈存入浏览器本地记录，并上报匿名事件用于后续迭代。

## 关键事件

- `daily_pool_expanded`
- `daily_feedback`（mode、action、reason）
- `daily_reroll`
- `daily_share_copy`

## 体验修复

- 复制操作提供可见 Toast。
- 未完成问卷时明确提示缺少项，并滚动聚焦到对应问题。
- 换一批期间显示加载状态并阻止重复点击。
- 恢复一次性轻量彩带；遵循 `prefers-reduced-motion`，并置于内容层下方。
- 标签输入为空或重复时禁用“添加”，避免无响应按钮。

## 验证

- 生产构建通过。
- 桌面端和 390px 移动端完整流程通过。
- 恐怖 + 悬疑场景可得到双轨结果，重选会排除上一轮两部电影。
- 反馈、拒绝原因、Toast 与响应式布局均完成回归。
